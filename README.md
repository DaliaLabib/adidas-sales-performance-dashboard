# Adidas Sales Performance Dashboard (MENA Region)

An interactive Excel sales analytics dashboard analyzing key revenue, profit, and volume metrics for Adidas across various Middle East & North Africa (MENA) markets.

## 📌 Dashboard Overview

The dashboard provides a visual analysis of Adidas's sales performance, channel distribution, regional revenue vs. profit metrics, and individual product profitability.

### Key Performance Indicators (KPIs)
* **Total Units Sold:** 3,550 units
* **Total Revenue:** $287,378
* **Total Profit:** $85,070

---

## 📊 Visualizations & Insights

1. **Sales Method Breakdown (Pie Chart):**
   * **Online:** 46%
   * **Retail:** 35%
   * **Outlet:** 12%
   * **Wholesale:** 7%

2. **Sales vs. Profit per Region (Clustered Bar Chart):**
   * **Regions Covered:** Egypt, Iraq, Oman, KSA, Lebanon
   * **Top Performing Market:** Egypt leads in both revenue ($85,028) and net profit ($25,519).

3. **Profit per Product (Bar Chart by Category):**
   * **Footwear:** *Predator Freak* ($9,218) and *Ultraboost Light* ($8,876) generate the highest profitability.
   * **Apparel:** *Primegreen Jacket* ($7,687) and *Z.N.E. Hoodie* ($7,070) lead apparel profits.
   * **Accessories:** *Originals Backpack* ($3,355) is the top performer in this category.

---

## 🎛 Interactivity & Filters (Slicers)

The dashboard allows dynamic data filtering using interactive slicers:
* **Order Date:** Year range (2023 – 2025)
* **Region:** Egypt, Iraq, KSA, Lebanon, Oman
* **Category:** Accessories, Apparel, Footwear
* **Store Type:** Online, Outlet, Retail, Wholesale
